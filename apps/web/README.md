# @ordra/web

Next.js application for Ordra.

## Structure

- `app/` — App Router routes (marketing, auth, dashboard, API)
- `components/` — Shared UI and layout components
- `features/` — Feature modules (business logic colocated by domain)
- `lib/` — Cross-cutting infrastructure (auth, db, ai, payments, logger)
- `hooks/` — Shared React hooks
- `types/` — App-local types
- `config/` — App configuration
