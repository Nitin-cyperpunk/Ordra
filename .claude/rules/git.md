# Git & Commit Rules

## Branches

- `main` — production-ready
- `develop` — integration
- `feature/*` — new work
- `fix/*` — bug fixes
- `hotfix/*` — urgent production fixes

## Commit prefixes

`feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`, `ci:`

## Examples

```text
feat: initialize ordra monorepo
docs: add system architecture
chore: configure eslint
```
